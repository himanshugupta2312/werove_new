# We Rove

- `site/` is the live website (Astro, published to https://www.werove.in by `.github/workflows/deploy.yml`). Run it locally with `npm install` then `npm run dev` inside `site/`.
- `archive/old-site/` is the previous website, kept for reference. It is not published.
- `mockups/` and `content-drafts/` are design and writing work from the redesign.
- `New assets/` holds the original photos. It is git-ignored (large, and the files carry GPS data).
